# 郑航小白 · DSH 智能体预设

郑州航空工业管理学院（郑航）的校园智能体，以 DeepSeek Harness（DSH）agent preset bundle 的形式提供。安装后，新建会话时可以在「智能体」里选择「郑航小白」。

本包同时包含一个**右侧栏面板**：查看校历、常用入口，以及登录教务系统导入课表；面板入口只在选择「郑航小白」模式时出现。

## 能力

### 智能体

- 校园问答：校区、学院、教务系统、校历、办事流程、校医院、宿舍、餐厅、快递
- 校园地图导航：龙子湖校区四门、教学楼、图书馆、餐厅、宿舍群、运动场方位
- 任务规划、活动汇总、基础学术解题
- 论文检索：Crossref / arXiv / PubMed / DOAJ / OSF / Semantic Scholar / OpenAlex 开放接口
- GitHub 公开仓库查阅
- 全套工具：文件读写、命令执行、子智能体、计划模式、网页搜索

### 郑航面板

选中「郑航小白」会话后，输入框右侧会出现「郑航」按钮，点开右侧栏面板：

- **校历**：当前是第几周、距考试周/寒暑假多少天。以校历为准：9 月 7 日为第 1 周，每周一进入新一周。
- **常用入口**：教务系统、智慧门户、教务处、选课指南、图书馆、校医院、招生办、学校官网；点击在右侧内置浏览器打开，不调用系统默认程序。
- **课表**：
  - 登录教务系统（学号/工号 + 密码），自动抓取当前周的课表
  - 解析后以「星期 × 节次」网格展示，今天那一列高亮，格子里显示课程名与教室
  - 解析依据教务系统页面里的 `TaskActivity` 数据，周次按课程自身的「第 n-m 周」过滤
  - 课表保存在本机浏览器 localStorage，不上传

## 安装

### 方式一：从 GitHub 直接安装（推荐）

在 DSH 里打开一个具备 `plugin_manager` 工具的会话（Standard 或 Creator 模式），对它说：

> 安装 bundle：`github:XH-Long08/dsh-zua-xiaobai-preset`

或者使用插件页「添加插件」输入同样的 git 地址。安装会请求 Full 权限确认。

### 方式二：克隆后本地安装

```sh
git clone https://github.com/XH-Long08/dsh-zua-xiaobai-preset.git
```

然后在 DSH 里让 agent 用 `plugin_manager` 的 `install_bundle` 指向克隆目录，或在插件页选择本地目录。

### 安装后

1. 设置 → 智能体，应能看到「郑航小白」卡片（自定义分组）。
2. 新建会话，选择「郑航小白」即可使用；面板按钮只在这个模式下出现。
3. 想默认使用，可在设置里把它设为默认。
4. 装完或更新后，刷新一次页面（Ctrl+R）加载新的客户端面板。

## 面板说明

- 面板的 Host 端在本机 `127.0.0.1:27127` 启动一个只监听回环地址的小服务，负责登录教务系统、抓取课表、解析课程。
- 登录时密码在本地服务内按教务系统页面的动态盐值做 SHA1 后提交；**密码不保存、不写浏览器存储**。
- 课表只保存课程名/教室/星期/节次/周次，保存在浏览器 localStorage。
- 周次以校历为准（9 月 7 日第 1 周、每周一换周），导入时会把当前周传给教务系统，不采用教务页面默认停留的周次。
- 若登录失败，面板会显示教务系统返回的原因（如「账号或密码异常」「请不要过快点击」）；连续失败时稍等再试。

## 仓库结构

| 路径 | 作用 |
|---|---|
| `package.json` | bundle 声明，`dsh.bundle.patch` 指向 cordis 补丁，`dsh.client` 声明面板 |
| `cordis.patch.yml` | 预设声明（人设、工具、技能）+ 面板 Host 行 |
| `index.js` | 面板 Host 端：本地登录/课表服务与解析 |
| `client.js` | 面板 Client 端：右侧栏 UI、课表网格、预设门控 |
| `skills/zua-campus/` | 郑航校园知识：学校概况、官网链接、校医院、校历、校园方位表 |
| `skills/github/` | GitHub 公开仓库查阅规则 |
| `skills/papers/` | 论文检索规则与聚合脚本 |

## 自定义

- 改人设：编辑 `cordis.patch.yml` 中 `persona` 的 `prefix`。
- 改校园资料：编辑 `skills/zua-campus/SKILL.md` 与 `references/`，技能正文是每次加载时现读的。
- 改面板：编辑 `client.js`（界面）和 `index.js`（登录/解析逻辑）。
- 改完提交并推送后，其他人重新安装或更新即可。

## 说明

- 校园数据整理于 2026-11，来源为学校官网、教务处、校医院与百度地图 POI；实时信息仍会由智能体联网核对。
- 面板依赖教务系统的页面结构，教务系统改版时可能需要调整 `index.js` 的解析逻辑。
- 本包需要 DSH 0.2 及以上版本；安装会执行 npm 包安装与插件激活，需要 Full 权限。
